How to lock a folder on Android

You have a folder of scans, receipts, voice notes or photos and you want a lock on it. Android makes that harder than it should be. This guide shows how to lock a folder on Android with what your phone already has, what a folder lock app adds, and which methods leave the files readable anyway.

Quick answer

Android can’t put a password on an ordinary folder where it sits. To lock a folder, move its files into a protected space: Samsung Secure Folder, Xiaomi’s private files in File Manager, Private Safe on OPPO, realme and OnePlus, Android 15’s Private space, or a folder lock app. Only options that encrypt the files keep them unreadable if someone opens the phone’s storage with a file manager or a computer.

Why you can’t just lock the folder itself

On a computer you can right-click a folder and protect it. Android’s shared storage doesn’t work that way. Every app that has file access, and every computer you plug the phone into, sees the same folders. There’s no per-folder password in the system.

So every method below does one of two things:

  • Moves the files somewhere other apps can’t reach, behind a lock. That’s what Secure Folder, private files, Private Safe and Private space do.
  • Turns the files into encrypted data that only one app can read with your key. That’s what a real vault does.

A third group of tricks only hides the folder from view. They’re fine for keeping a gallery tidy, but they aren’t a lock.

Lock a folder with your phone’s built-in tools

Menu names shift between software versions. If a step doesn’t match your screen, search Settings for the feature name.

Samsung Galaxy: Secure Folder

  1. Open Secure Folder and unlock it. If it isn’t set up, search Settings for “Secure Folder”. It needs a Samsung account.
  2. Tap More options (⋮), then Add files.
  3. Pick a category, or choose My Files to browse to the folder you want to lock.
  4. Select the files and choose Move rather than Copy, so nothing is left behind.

You can also go the other way: in My Files or Gallery, select items, tap More and choose Move to Secure Folder. Samsung notes this only works from its own apps. Inside Secure Folder, open its own My Files to find what you moved.

Xiaomi, Redmi and POCO: private files

  1. In Settings, open the fingerprint and screen lock section and set a Privacy protection password.
  2. Open File Manager, press and hold a file or folder, tap More and choose Make private.
  3. To open them again, go to File Manager’s start page, pull down and release, then enter your privacy password.

OPPO, realme and OnePlus: Private Safe

ColorOS, realme UI and OxygenOS have Private Safe under Settings → Security and privacy (the exact wording varies). After you set a privacy password, you can mark files as private from the file manager, and they move into the safe.

Android 15 and newer: Private space

Settings → Security & privacy → Private space creates a separate locked profile with its own lock. Install a file manager inside it and keep the files there. When the space is locked, its apps and files are out of reach of the main profile. It’s strong, but it’s a whole second profile, and not every phone has it yet.

Any phone: Safe folder in Files by Google

The free Files by Google app has a Safe folder under Browse → Collections. Set a PIN or pattern, then select files, tap More and choose Move to Safe folder. Files inside don’t show in other apps. Two cautions: it only protects files you move into it, and Google warns that uninstalling the app or clearing its data can delete what’s inside, so keep a copy elsewhere.

Folder lock without software: the hiding tricks

“Folder lock without software” is a common search. Here’s what those methods really do.

  • Add a dot to the folder name (for example .receipts). Most file managers hide it until you turn on “show hidden files”. One tap undoes it.
  • Put an empty .nomedia file in the folder. Gallery apps stop indexing it. File managers and computers still open the photos normally.
  • Hide an album in the gallery. The album tile disappears; the files don’t move and aren’t locked.

None of these needs a password to reverse. They keep a casual glance away, nothing more. If you’re after photos specifically, our gallery lock guide covers each brand’s private album.

What “encrypted” changes, and why it matters for folders

A lock screen controls who can open an app. Encryption controls who can read the files, wherever they end up. That difference shows up in real situations:

  • You plug the phone into a computer to charge or copy music. A hidden folder is right there in the file list. An encrypted file is noise.
  • You give the phone to someone with a file manager app. Folder lock apps that just move files into a renamed folder are found in a minute.
  • The phone is lost while unlocked, or sent for repair. Only encrypted files stay private when the phone itself is open.

Search terms like “folder lock encryption for Android” are really asking this: does the app scramble the files, or just hide them? The app’s store listing or website should answer clearly. If it only says “secure” or “private”, assume hiding.

Choosing a folder lock app

  • Files encrypted on the phone, not just moved.

Mistakes to avoid

  • Copying instead of moving. The unlocked originals stay where they were. Check the old folder, Downloads and WhatsApp’s media folders afterwards.
  • Trusting a dot or .nomedia. It’s a curtain, not a lock.
  • Reusing your phone’s PIN. Anyone who has seen you unlock the phone has the key.
  • No backup. Secure folders and vault apps live on the phone. A reset, an uninstall or a lost phone takes them with it.
  • Losing the recovery code. Apps that truly encrypt can’t reset your access for you.

Bottom line

You can’t password-protect a folder in place on Android, but you can move its contents somewhere locked. On Samsung, Xiaomi, OPPO, realme and OnePlus, the built-in secure area is a good free start. On Android 15, Private space adds a full separate profile. For one lock that works the same on any phone and keeps files encrypted outside the app, use a vault that states its encryption plainly. Frequently asked questions

Can I put a password on a folder in Android without an app?

Not on a normal folder. Android has no setting to password-protect a single folder in place. Without installing anything you can use your phone's own secure area (Secure Folder on Samsung, private files on Xiaomi, Private Safe on OPPO, realme and OnePlus) or Android 15's Private space, and move the files into it.

Does renaming a folder with a dot or adding .nomedia lock it?

No. A dot at the start of the name or a .nomedia file only stops the gallery and some file managers from showing the contents. Any file manager with 'show hidden files' turned on, or a computer over USB, can open them with no password.

What is the best folder lock app for Android?

Pick one that encrypts the files themselves, uses a lock separate from your phone's screen lock, needs no account and gives you a written recovery code. Avoid apps that only hide files behind a password screen, because the files stay readable with a file manager.

If I uninstall a folder lock app, what happens to my files?

With an app that encrypts, the files go with it unless you made a backup or moved them out first. Built-in secure folders can also be wiped by a factory reset. Always move files out or back them up before uninstalling or resetting.

Can I lock an SD card folder on Android?

Built-in secure folders usually copy files into protected internal storage rather than locking the SD card folder. Files left on the card stay readable in any card reader, so move them into an encrypted vault and delete the card copies.
