Cadangan terenkripsi: pindahkan brankas ke ponsel baru

Brankas offline perlu rencana untuk ponsel yang hilang atau rusak. Cadangan Sealcloak berupa satu file terenkripsi yang bisa Anda simpan di mana saja.

Singkatnya

Ekspor cadangan di Setelan dan Sealcloak menulis satu file terenkripsi ke folder pilihan Anda, lalu memeriksa bahwa file itu bisa dibaca kembali. Kunci dengan frasa pemulihan atau frasa sandi. Untuk memulihkan, instal Sealcloak di ponsel baru, pilih Pulihkan dari cadangan, dan masukkan frasa atau frasa sandi yang sama. Cadangan terjadwal bisa berjalan sendiri setiap minggu atau bulan.

Membuat cadangan

  1. Di Setelan, pada bagian Cadangan, ketuk Ekspor cadangan.
  2. Pilih Gunakan frasa pemulihan saya (disarankan) atau frasa sandi minimal 8 karakter.
  3. Pilih tempat menyimpan file.
  4. Tunggu sampai muncul Cadangan terverifikasi. Aplikasi membaca ulang file untuk memeriksanya.

Cadangan terjadwal

Atur cadangan terjadwal agar file tersimpan sendiri setiap minggu atau bulan, ke folder pilihan Anda. Jika folder itu dipantau oleh Drive atau aplikasi sinkronisasi lain, file terenkripsi otomatis tersalin keluar dari ponsel, tanpa Sealcloak sendiri pernah menyentuh internet.

Memulihkan di ponsel baru

  1. Salin file cadangan ke ponsel baru.
  2. Instal Sealcloak dan ketuk Pulihkan dari cadangan.
  3. Atur pola untuk brankas baru dan catat frasa pemulihannya.
  4. Pilih file cadangan dan masukkan frasa atau frasa sandinya.

Impor aman diulang: file yang sudah Anda miliki akan dilewati.

Simpan filenya dengan aman

Filenya terenkripsi, tetapi privasinya hanya sebaik tempat Anda menyimpannya, dan siapa pun yang punya file sekaligus kuncinya bisa membukanya. Tulis kuncinya di kertas, terpisah dari file. Cek keamanan di aplikasi akan mengingatkan jika belum ada cadangan terbaru. Frasanya juga hilang? Lihat frasa pemulihan.
