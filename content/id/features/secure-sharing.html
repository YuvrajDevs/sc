Fitur · Berbagi dengan aman

Bagikan file dengan aman sebagai paket berkunci frasa sandi

Terkadang file pribadi perlu sampai ke satu orang lain. Sealcloak mengemasnya menjadi file terenkripsi yang hanya bisa dibuka dengan frasa sandi.

Singkatnya

Pilih file atau folder di brankas lalu pilih Bagikan dengan aman. Sealcloak membuat satu paket terenkripsi yang dikunci dengan frasa sandi pilihan Anda. Kirim filenya lewat aplikasi apa pun, dan berikan frasa sandinya di pesan terpisah. Penerima mengimpornya ke Sealcloak dengan frasa sandi tersebut.

Mengirim

  1. Tekan lama sebuah file, atau pilih beberapa, atau buka folder lalu pilih Bagikan folder ini.
  2. Pilih Bagikan dengan aman dan atur frasa sandi.
  3. Kirim paketnya lewat WhatsApp, email, Drive, atau aplikasi lain.
  4. Berikan frasa sandinya dengan cara lain: langsung bertatap muka, lewat telepon, atau di aplikasi yang berbeda.

Menerima

Penerima membuka Sealcloak, memilih Impor cadangan di Setelan, memilih paketnya, lalu memasukkan frasa sandi. File-file masuk ke brankasnya dalam keadaan terenkripsi.

Kegunaan yang tepat

Mengirim hasil pindaian KTP ke anggota keluarga, berbagi dokumen medis dengan orang yang Anda percaya, atau memindahkan beberapa file dari brankas ke ponsel lain tanpa membuat cadangan lengkap.

Kenapa jalur terpisah itu penting

Siapa pun yang punya file sekaligus frasa sandinya bisa membukanya. Mengirim keduanya bersamaan di satu chat berarti satu kebocoran membongkar keduanya. Memisahkannya lewat jalur berbeda itulah yang membuat paket aman selama dikirim. Untuk cara lain berbagi secara pribadi, lihat aplikasi brankas tanpa akun.
