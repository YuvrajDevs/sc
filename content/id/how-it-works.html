Cara kerja

Dari instal sampai tersembunyi, cukup semenit.

Gambar pola Anda

Hubungkan setidaknya enam titik di kisi 5×5. Gambar dua kali untuk konfirmasi.

Simpan frasa Anda

Tulis sembilan kata itu di kertas, atau gunakan kalimat Anda sendiri. Simpan jauh dari ponsel.

Tambahkan file

Ketuk + lalu pilih foto, video, dokumen, atau audio. Setelah itu hapus file aslinya dari galeri.

Sehari-hari

Buka, lihat, kunci.

Gambar pola atau pakai sidik jari. Ketuk Kunci sekarang, atau tinggalkan saja aplikasinya dan ia akan terkunci sendiri.

Lupa pola

Frasa Anda membuka jalan kembali.

Ketuk “Gunakan frasa pemulihan”, ketik frasanya, lalu gambar pola baru. Pola lama tidak berlaku lagi.

harbor · velvet · ninety
lantern · copper · meadow
orbit · thistle · canyon
Kalau sudah siap

Lebih jauh lagi.

Tambah brankas lain

Setelan → Brankas lainnya. Gambar pola baru. Pola itu membuka brankasnya sendiri.

Buat cadangan

Setelan → Cadangan. Ekspor sekali, atau jadwalkan cadangan mingguan atau bulanan ke sebuah folder.

Sembunyikan aplikasi

Setelan → Ikon kustom (Pro). Pilih gambar dan nama, dan Sealcloak tampak seperti aplikasi lain.

Ponsel baru

Pindah ke ponsel baru.

Ekspor

Di ponsel lama, ekspor cadangan setiap brankas.

Salin

Pindahkan file cadangan lewat kabel, flashdisk, atau aplikasi apa pun.

Impor

Instal Sealcloak, pilih Impor cadangan, lalu ketik frasa pemulihan brankas tersebut.

Siap kapan pun Anda siap.
