Pertanyaan Anda, terjawab.

Privasi

Apakah Sealcloak mengunggah foto saya ke suatu tempat?

Tidak. Aplikasi ini tidak punya izin internet, jadi tidak bisa mengunggah apa pun. File Anda dienkripsi dan tetap di ponsel Anda.

Apakah saya perlu akun?

Tidak. Tanpa email, tanpa nomor HP, tanpa login. Pola Anda adalah satu-satunya kunci.

Bisakah kalian melihat file saya?

Tidak. Kami tidak punya server dan tidak menyimpan salinan file maupun kunci Anda. Semuanya dienkripsi di ponsel Anda.

Apakah foto tetap ada di galeri saya?

Menambahkan foto akan membuat salinan terenkripsi di brankas. Foto aslinya tetap di galeri sampai Anda menghapusnya di sana, jadi Anda bisa memeriksa salinan di brankas lebih dulu.

Membuka brankas

Bagaimana kalau saya lupa pola?

Ketuk “Gunakan frasa pemulihan” di layar pola, lalu ketik frasa yang Anda simpan saat pengaturan awal. Setelah itu gambar pola baru.

Bagaimana kalau saya lupa pola dan kehilangan frasa pemulihan?

Kalau begitu, tidak ada yang bisa membuka brankas itu, termasuk kami. Tidak ada pintu belakang. Simpan frasa Anda di kertas di tempat yang aman.

Bisakah saya pakai sidik jari?

Bisa. Aktifkan buka kunci dengan sidik jari di Setelan. Pola Anda tetap bisa dipakai.

Apa itu Coerce?

Brankas kedua yang tampak biasa saja, dengan polanya sendiri. Jika seseorang memaksa Anda membuka aplikasi, gambar pola itu saja.

Coerce juga bisa menghapus brankas Anda yang lain saat dibuka, tetapi fitur ini nonaktif secara default dan Anda harus mengetik PERMIT untuk menyalakannya.

Cadangan & ganti ponsel

Bagaimana cara memindahkan brankas ke ponsel baru?

Ekspor cadangan di ponsel lama, salin filenya ke ponsel baru, instal Sealcloak, lalu impor dengan frasa pemulihan brankas tersebut.

Apa yang terjadi kalau aplikasinya saya hapus?

Brankas-brankasnya ikut terhapus dari ponsel. File cadangan yang sudah Anda ekspor sebelumnya tetap ada dan bisa diimpor lagi.

Apakah cadangannya dienkripsi?

Ya. File cadangan tidak berguna tanpa frasa pemulihan brankas tersebut.

Apakah Sealcloak tersedia untuk iPhone?

Belum. Sealcloak adalah aplikasi Android.

Pro

Apa saja tambahan di Pro?

Brankas dan file tanpa batas, plus menyamarkan aplikasi sebagai aplikasi lain dengan ikon dan nama pilihan Anda.

Apakah file saya hilang kalau berhenti berlangganan?

Tidak. Semuanya tetap ada dan tetap berfungsi. Anda hanya tidak bisa menambah lebih dari batas gratis.
