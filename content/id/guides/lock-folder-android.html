Cara mengunci folder di Android

Anda punya folder berisi hasil pindaian, struk, rekaman suara, atau foto, dan ingin menguncinya. Android membuat hal itu lebih sulit dari yang seharusnya. Panduan ini menunjukkan cara mengunci folder di Android dengan fitur yang sudah ada di ponsel Anda, apa tambahan dari aplikasi pengunci folder, dan cara mana yang tetap membiarkan file bisa dibaca.

Jawaban singkat

Android tidak bisa memasang kata sandi pada folder biasa di tempatnya. Untuk mengunci folder, pindahkan isinya ke ruang yang terlindungi: Folder Aman Samsung, file pribadi di Pengelola File Xiaomi, Brankas Pribadi di OPPO, realme, dan OnePlus, Ruang pribadi di Android 15, atau aplikasi pengunci folder. Hanya opsi yang mengenkripsi file yang membuatnya tetap tidak terbaca jika seseorang membuka penyimpanan ponsel dengan pengelola file atau komputer.

Kenapa folder tidak bisa langsung dikunci

Di komputer, Anda bisa klik kanan sebuah folder lalu melindunginya. Penyimpanan bersama di Android tidak bekerja seperti itu. Setiap aplikasi yang punya akses file, dan setiap komputer yang disambungkan ke ponsel, melihat folder yang sama. Sistem tidak menyediakan kata sandi per folder.

Jadi setiap cara di bawah ini melakukan salah satu dari dua hal:

  • Memindahkan file ke tempat yang tidak bisa dijangkau aplikasi lain, di balik kunci. Itulah yang dilakukan Folder Aman, file pribadi, Brankas Pribadi, dan Ruang pribadi.
  • Mengubah file menjadi data terenkripsi yang hanya bisa dibaca satu aplikasi dengan kunci Anda. Itulah yang dilakukan brankas sungguhan.

Kelompok trik ketiga hanya menyembunyikan folder dari pandangan. Cukup untuk merapikan galeri, tetapi itu bukan kunci.

Kunci folder dengan fitur bawaan ponsel

Nama menu berubah-ubah antarversi perangkat lunak. Jika suatu langkah tidak cocok dengan layar Anda, cari nama fiturnya di Setelan.

Samsung Galaxy: Folder Aman

  1. Buka Folder Aman (“Secure Folder”) dan buka kuncinya. Jika belum diatur, cari “Folder Aman” di Pengaturan. Fitur ini memerlukan akun Samsung.
  2. Ketuk Opsi lainnya (⋮), lalu Tambahkan file.
  3. Pilih kategori, atau pilih File Saya untuk menelusuri folder yang ingin Anda kunci.
  4. Pilih filenya lalu pilih Pindahkan, bukan Salin, agar tidak ada yang tertinggal.

Anda juga bisa melakukannya dari arah sebaliknya: di File Saya atau Galeri, pilih item, ketuk Lainnya, lalu pilih Pindahkan ke Folder Aman. Samsung mencatat bahwa cara ini hanya berfungsi dari aplikasi buatannya sendiri. Di dalam Folder Aman, buka File Saya miliknya untuk menemukan file yang Anda pindahkan.

Xiaomi, Redmi, dan POCO: file pribadi

  1. Di Setelan, buka bagian sidik jari dan kunci layar, lalu atur Kata sandi perlindungan privasi.
  2. Buka Pengelola File, tekan lama sebuah file atau folder, ketuk Lainnya, lalu pilih Jadikan pribadi.
  3. Untuk membukanya lagi, buka halaman awal Pengelola File, tarik ke bawah lalu lepaskan, kemudian masukkan kata sandi privasi Anda.

OPPO, realme, dan OnePlus: Brankas Pribadi

ColorOS, realme UI, dan OxygenOS punya Brankas Pribadi (“Private Safe”) di Setelan → Keamanan dan privasi (kata-katanya bisa sedikit berbeda). Setelah mengatur kata sandi privasi, Anda bisa menandai file sebagai pribadi dari pengelola file, dan file itu pindah ke brankas.

Android 15 dan yang lebih baru: Ruang pribadi

Setelan → Keamanan & privasi → Ruang pribadi (“Private space”) membuat profil terkunci yang terpisah dengan kuncinya sendiri. Instal pengelola file di dalamnya dan simpan file di sana. Saat ruang ini terkunci, aplikasi dan filenya tidak bisa dijangkau dari profil utama. Fitur ini kuat, tetapi berupa profil kedua yang utuh, dan belum semua ponsel memilikinya.

Ponsel apa pun: Folder aman di Files by Google

Aplikasi gratis Files by Google punya Folder aman di Jelajahi → Koleksi. Atur PIN atau pola, lalu pilih file, ketuk Lainnya, dan pilih Pindahkan ke Folder aman. File di dalamnya tidak muncul di aplikasi lain. Dua hal yang perlu diwaspadai: fitur ini hanya melindungi file yang Anda pindahkan ke dalamnya, dan Google memperingatkan bahwa menghapus aplikasi atau menghapus datanya bisa menghapus isinya, jadi simpan salinan di tempat lain.

Kunci folder tanpa aplikasi: trik menyembunyikan

“Cara mengunci folder tanpa aplikasi” adalah pencarian yang umum. Inilah yang sebenarnya dilakukan cara-cara tersebut.

  • Tambahkan titik di depan nama folder (misalnya .receipts). Kebanyakan pengelola file menyembunyikannya sampai Anda menyalakan “tampilkan file tersembunyi”. Satu ketukan sudah membatalkannya.
  • Taruh file .nomedia kosong di dalam folder. Aplikasi galeri berhenti memindainya. Pengelola file dan komputer tetap membuka fotonya seperti biasa.
  • Sembunyikan album di galeri. Kotak albumnya hilang; filenya tidak berpindah dan tidak terkunci.

Tidak satu pun perlu kata sandi untuk dibatalkan. Cara-cara ini hanya menghalau lirikan sekilas, tidak lebih. Jika yang Anda cari khusus foto, panduan kunci galeri kami membahas album pribadi setiap merek.

Apa yang diubah oleh “terenkripsi”, dan kenapa penting untuk folder

Layar kunci mengatur siapa yang bisa membuka aplikasi. Enkripsi mengatur siapa yang bisa membaca file, di mana pun file itu berakhir. Perbedaan itu terlihat dalam situasi nyata:

  • Anda menyambungkan ponsel ke komputer untuk mengisi daya atau menyalin musik. Folder tersembunyi langsung terlihat di daftar file. File terenkripsi hanya berupa data acak.
  • Anda memberikan ponsel kepada orang yang punya aplikasi pengelola file. Aplikasi pengunci folder yang hanya memindahkan file ke folder yang diganti namanya bisa ditemukan dalam semenit.
  • Ponsel hilang dalam keadaan tidak terkunci, atau dibawa ke tempat servis. Hanya file terenkripsi yang tetap pribadi saat ponselnya sendiri terbuka.

Pencarian seperti “aplikasi kunci folder dengan enkripsi untuk Android” sebenarnya menanyakan hal ini: apakah aplikasinya mengacak file, atau hanya menyembunyikannya? Halaman Play Store atau situs web aplikasi seharusnya menjawabnya dengan jelas. Jika hanya tertulis “aman” atau “privat”, anggap saja hanya disembunyikan.

Memilih aplikasi pengunci folder

Jika ponsel Anda tidak punya area aman bawaan, atau Anda ingin kunci yang sama di semua ponsel Anda, aplikasi adalah satu-satunya jalan. Periksa hal-hal ini sebelum memercayakan folder berisi file pribadi:

  • File dienkripsi di ponsel, bukan sekadar dipindahkan.
  • Kunci yang bukan kunci layar Anda, agar orang yang tahu PIN ponsel tetap tidak bisa masuk.
  • Tanpa akun dan tanpa unggahan. Selengkapnya di aplikasi brankas foto tanpa akun.
  • Kode pemulihan yang Anda tulis, dan cadangan terenkripsi dalam kendali Anda.
  • Folder di dalam aplikasi, agar struktur folder Anda tetap terjaga setelah dipindahkan.

Sealcloak adalah salah satu aplikasi yang dibuat dengan cara ini. File yang Anda tambahkan dienkripsi di ponsel dengan AES-256-GCM, brankas dibuka dengan pola 5×5 sendiri (sidik jari opsional), dan sama sekali tidak ada akun maupun izin internet. Di dalamnya, Anda bisa membuat folder dan menyimpan foto, video, PDF dan dokumen lain, audio, serta catatan teks, lengkap dengan pencarian dan fitur pindah atau salin antarfolder. Jika Anda lupa pola, frasa pemulihan 9 kata membawa Anda masuk lagi. Sealcloak tidak bisa mengunci folder di tempatnya: Anda menambahkan file ke brankas, memastikan file bisa dibuka, lalu menghapus sendiri file aslinya. Paket gratis menampung 100 foto, 10 video, 10 dokumen, dan 10 file audio; Pro menghapus batasannya (lihat semua fitur). Halaman keamanan menjelaskan enkripsinya secara rinci.

Mengunci folder dengan Sealcloak, langkah demi langkah

  1. Instal Sealcloak dan gambar pola minimal 6 titik di kisi 5×5.
  2. Tulis frasa pemulihan 9 kata di kertas dan simpan di tempat yang aman.
  3. Buat folder di brankas dengan nama yang sama seperti folder yang ingin Anda kunci.
  4. Ketuk + lalu tambahkan file: gambar, video, dokumen, atau audio.
  5. Buka beberapa file untuk memastikan semuanya berfungsi, lalu hapus file aslinya dari pengelola file ponsel.
  6. Atur cadangan terenkripsi ke folder pilihan Anda, secara manual atau dengan jadwal mingguan atau bulanan.

Dokumen kertas bisa masuk tanpa pernah menyentuh galeri: pemindai bawaan membuat PDF langsung di dalam brankas. Jika Anda juga ingin aplikasinya sendiri tampak biasa, lihat cara menyembunyikan aplikasi di Android.

Kesalahan yang perlu dihindari

  • Menyalin, bukan memindahkan. File asli yang tidak terkunci tetap di tempatnya. Periksa folder lama, Download, dan folder media WhatsApp setelahnya.
  • Percaya pada titik atau .nomedia. Itu hanya tirai, bukan kunci.
  • Memakai ulang PIN ponsel. Siapa pun yang pernah melihat Anda membuka kunci ponsel sudah memegang kuncinya.
  • Tidak punya cadangan. Folder aman dan aplikasi brankas tersimpan di ponsel. Reset, hapus aplikasi, atau ponsel hilang akan ikut membawanya.
  • Kehilangan kode pemulihan. Aplikasi yang benar-benar mengenkripsi tidak bisa mereset akses Anda.

Kesimpulannya

Anda tidak bisa melindungi folder dengan kata sandi di tempatnya di Android, tetapi Anda bisa memindahkan isinya ke tempat yang terkunci. Di Samsung, Xiaomi, OPPO, realme, dan OnePlus, area aman bawaan adalah awal yang baik dan gratis. Di Android 15, Ruang pribadi menambahkan profil terpisah yang utuh. Untuk satu kunci yang bekerja sama di ponsel apa pun dan membuat file tetap terenkripsi di luar aplikasi, gunakan brankas yang menyatakan enkripsinya dengan jelas. Hanya foto? Mulailah dengan cara menyembunyikan foto di Android.
