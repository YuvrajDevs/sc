WiFi QR code generator

Let guests join your Wi-Fi by pointing their camera at a code, with no reading out long passwords. Print it for your home, office, shop or Airbnb.

Quick answer

To make a Wi-Fi QR code, type your network name and password above, choose the security type (usually WPA), and download the code. Guests scan it with their phone camera and connect straight away. The password is never sent anywhere.

How to make your Wi-Fi QR code

  1. Type the network name exactly as it appears in your Wi-Fi list, including capitals and spaces.
  2. Type the password and choose the security: WPA covers WPA, WPA2 and WPA3, which is almost every router today.
  3. Tick Hidden network only if your network doesn't appear in the Wi-Fi list.
  4. Download it and test with your phone: open the camera, point it at the code and tap Connect.

Where to find your network name and password

They're usually on a sticker on the router. On Android you can also open Settings, then Wi-Fi, tap your network and choose Share; on many phones this shows the password under a QR code after you unlock. On an iPhone, Settings, then Wi-Fi, then the ⓘ next to your network shows the password after Face ID.

Use a guest network

If your router supports it, create a separate guest network and put that on the code. Guests then can't see your other devices, and you can change the guest password at any time without reconnecting your own phones and TV.

Make it scan reliably

  • Keep strong contrast: a dark code on a light background. Light codes on dark backgrounds don't scan on every phone.
  • Leave the white border around the code; scanners need it.
  • Print it big enough: at least 2 × 2 cm, and bigger for posters read from a distance.
  • Use higher error correction if the code may get scratched, folded or partly covered.
  • Test it with your phone camera before printing hundreds.

Private by design

The code is generated inside this browser tab using a small open-source library. What you type, including Wi-Fi passwords, is never sent to a server, and there is no tracking. The code is static: it contains your text directly, so it never expires and doesn't depend on any website staying online.

SVG or PNG?

PNG is an image that works everywhere: messages, documents and social media. SVG is a vector file that stays perfectly sharp at any size, which is what print shops and designers prefer for posters, menus and packaging.

Codes that open links are only as safe as the link. Be careful scanning codes from strangers; our guide to keeping photos private and how encryption protects your files cover the basics of staying in control of your data.
