How to send files securely

Email, chat apps and cloud links weren't designed for passports, contracts and medical records. The simplest safe habit: encrypt the file with a password first, then send the password a different way.

Quick answer

Type a strong password above, choose the file, and send the .locked copy by email, chat or cloud link. Tell the recipient the password by phone call or in person, not in the same message. They open this page, enter the password and get the original file back.

Step by step

  1. Make a strong password; a random passphrase is easy to read out.
  2. Encrypt the file above. You get name.locked, encrypted with AES-256-GCM.
  3. Send the .locked file any way you like.
  4. Share the password separately: a call, a text to a different app, or in person.
  5. The recipient opens this page, types the password and chooses the .locked file.

Why encrypt before sending

  • Emails sit in inboxes, backups and servers for years.
  • Forwarded or misaddressed messages expose attachments.
  • Cloud links can be shared further than you intended.

An encrypted file stays unreadable in all those places without the password.

Good practice

  • Never put the password in the same email or chat as the file.
  • Use a different password for each recipient or batch.
  • Delete your unencrypted copy from Downloads once it's sent, or keep it in an encrypted vault.

Sealcloak can also send files from your vault as a passphrase-locked package.

Private by design

The encrypt a file tool on this page runs entirely inside your browser tab. Your files are opened, processed and saved on your own device and are never sent to a server, so there's nothing for anyone to store, scan or leak. There's no sign-up, no watermark and no limit, and once the page has loaded it keeps working even if you switch off your internet.
