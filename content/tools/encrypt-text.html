Encrypt text with a password

Send a private note, an address or a code through any chat or email as scrambled text that only someone with the password can read.

Quick answer

To encrypt text, type your message and a password above and tap Encrypt. Copy the result, which starts with sc1., and send it anywhere. The recipient pastes it here with the same password and taps Decrypt. Encryption uses AES-256-GCM in your browser.

How to use it

  1. Type or paste your message.
  2. Choose a strong password; a random passphrase is easy to share by phone.
  3. Tap Encrypt and copy the result.
  4. Send it by chat or email, and share the password a different way.
  5. To read it, paste the encrypted text here, type the password and tap Decrypt.

How secure is it?

Your password is stretched into a key with PBKDF2-SHA256 over 600,000 rounds and a random salt, and the message is encrypted with AES-256-GCM, which also detects any change to the encrypted text. With a strong password, the message can't realistically be read without it. A weak password is the main risk, so check it with the password strength checker.

Private by design

Everything happens in this browser tab using your browser's built-in Web Crypto. Your message and password are never sent to a server or stored. For files instead of text, use encrypt a file.
