Encrypt a file with a password

Lock any file (a PDF, photo, video or document) with a password before you email it, put it on a USB stick or store it in the cloud. Only someone with the password can open it.

Quick answer

To encrypt a file with a password, type a strong password above, then choose the file. You get a .locked copy encrypted with AES-256-GCM. To open it again, come back to this page, type the same password and choose the .locked file. Nothing is uploaded.

How to encrypt and decrypt a file

  1. Type a strong password. A random passphrase is ideal.
  2. Choose the file. You get a copy ending in .locked; the original isn't changed.
  3. Send or store the .locked file. Share the password a different way, for example by phone call rather than in the same email.
  4. To open it: on this page, type the same password and choose the .locked file. The original file comes back with its name.

How the encryption works

Your password is stretched into a 256-bit key with PBKDF2-SHA256 over 600,000 rounds and a random salt, which makes guessing passwords slow. The file is then encrypted with AES-256-GCM, which also detects tampering: if a single byte of the .locked file is changed, it refuses to decrypt instead of giving you a corrupted file. Everything runs through your browser's built-in Web Crypto, on your device.

Private by design

The file is read, encrypted and saved inside this browser tab. It's never sent to a server, and the password is never stored. That also means nobody can recover a forgotten password, including us, so keep it somewhere safe.

For files on your phone

This tool is for one-off files you send or store elsewhere. For photos, videos and documents you keep on your Android phone, Sealcloak does the same kind of protection automatically: every file is encrypted with AES-256-GCM as you add it, inside vaults that open with your own pattern, and it can make passphrase-locked packages for sharing.
