SHA-256 and MD5 checksum generator

Check that a download hasn't been changed or corrupted, or get the fingerprint of any file or text. Paste an expected checksum to compare automatically.

Quick answer

To get a file's checksum, drop it above; you'll see its MD5, SHA-1, SHA-256 and SHA-512 hashes. To verify a download, paste the checksum the publisher gives into the compare box; a green match means the file is identical. Nothing is uploaded.

How to verify a download

  1. Find the checksum on the publisher's download page, usually labelled SHA-256.
  2. Paste it into Compare with.
  3. Drop the downloaded file above.
  4. A ✓ match means the file is exactly what the publisher released.

Which algorithm?

AlgorithmUse today
SHA-256The standard choice for verifying downloads
SHA-512Also secure; longer output
SHA-1Legacy; not safe against deliberate tampering
MD5Legacy; fine for spotting accidental corruption only

Private by design

Files and text are hashed in your browser with its built-in Web Crypto (and a small MD5 routine), so even large files never leave your device. Encryption is a different thing from hashing: to lock a file with a password, use encrypt a file.
