Rotate PDF

Scanned a page sideways, or got a PDF that opens upside down? Rotate all pages or just the wrong ones, and save the fix permanently.

Quick answer

To rotate a PDF, choose it above, pick 90° clockwise, 180° or 90° anticlockwise, type the pages to turn (or leave blank for all), and tap Rotate PDF. The saved file stays rotated in every app. Nothing is uploaded.

How to rotate pages

  1. Choose the PDF.
  2. Pick the rotation: 90° clockwise, 180° (upside down) or 90° anticlockwise.
  3. Type the pages that need turning, like 2, 4-6, or leave it blank to rotate every page.
  4. Tap Rotate PDF and download.

Rotate in a viewer vs rotate the file

Most PDF viewers can turn a page on screen, but the next person who opens the file sees it sideways again. Rotating here changes the page itself, so it opens the right way everywhere: email, print, upload portals and phones.

For multi-page scans where only some pages are wrong, rotate just those pages. If a whole scan is sideways, leave Pages blank.
