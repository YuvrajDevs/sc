Photo vault password reset: how to get back into your vault

You open your photo vault and the code doesn't work, or it's been months and you simply can't remember it. A photo vault password reset is possible in many apps, but how it works depends entirely on what you set up on day one. This page shows the reset path for the common Android vaults, what to avoid while you try, and how to make sure it never happens again.

Quick answer

Stop guessing, and don't uninstall the app or clear its data, because that usually deletes the hidden photos. Look for Forgot or Reset on the vault's lock screen: most apps send a code to the recovery email you gave at setup, Samsung Secure Folder can reset through your Samsung account if that option was on, and Google Photos Locked Folder uses your phone's screen lock. If no recovery method was set up, the app often can't reset it, and a backup is your only way back.

First, three things not to do

When a vault won't open, the natural reaction is to try things. Some of them make the problem permanent.

  • Don't keep guessing quickly. Many vaults add waits after wrong attempts, and some can be set to erase themselves after a number of failures. A few calm, deliberate tries are fine. Twenty rushed ones may not be.
  • Don't uninstall, reinstall or clear app data. Vault apps keep their files in the app's private storage. Android deletes that storage when the app is removed or its data is cleared. You'd get a fresh, empty vault with a new code and lose everything that was in it.
  • Don't pay for "vault password recovery" software before trying the app's own options. Most search results for this problem are adverts for paid tools. A properly encrypted vault can't be read without its key, and the tools that claim otherwise usually only work on weak or very old apps, if at all.

Step-by-step: how to reset a photo vault password

  1. Work out which kind of vault you have. Is it a separate app from Google Play, or something built into the phone, like Samsung Secure Folder, Google Photos Locked Folder or the Safe folder in Files by Google? The reset path is different for each.
  2. Try the codes you're likely to have used. Old screen lock PINs, a pattern you used on a previous phone, a birthday. Do it slowly, and stop if the app starts adding waits.
  3. Find the Forgot or Reset option. It's usually on the lock screen itself, sometimes only after one wrong attempt, or in a three-dot menu at the top.
  4. Check the recovery inbox. If the app sends a code by email, look in spam and promotions folders too, and give it a few minutes. Some apps delay the email on purpose so a thief holding your phone can't reset it instantly.
  5. Contact the app's support from the right address. If the email doesn't arrive, write to support from the same email you registered. Many developers won't help from an address that isn't linked to the account.
  6. Fall back to a backup. If the vault can't be reset, an earlier backup of its contents, if you made one, is your only way back. Restore it to a fresh vault.

Keepsafe

Keepsafe ties every vault to an email address. On Android, open the three-dot menu on the lock screen, choose Reset PIN and tap Send code. Keepsafe says the code email is delayed by about five minutes for security. If you added an alternate email, that can be used too. Keepsafe's own help pages are blunt about the hard case: if you've permanently lost access to the only email you verified, the account and its contents can't be recovered. Samsung Secure Folder

Samsung's reset only exists if you switched on Reset with Samsung account when you chose the Secure Folder lock. If you did, enter a wrong PIN, pattern or password, tap Forgot, then Reset, sign in to your Samsung account and set a new lock. If that option was never turned on, the Forgot prompt doesn't appear. The remaining route is to remove Secure Folder and set it up again, which deletes what was in it. Our Samsung hidden photos guide covers Secure Folder in more detail.

Files by Google Safe folder

Google's help page says it plainly: if you forget your Safe folder PIN or pattern, you can't access your files. There is a reset in the app's settings, but it permanently deletes everything in the Safe folder before letting you choose a new code. Uninstalling Files by Google deletes those files too. See Sealcloak vs Files by Google Safe folder.

Google Photos Locked Folder

Locked Folder has no password of its own. Google says it uses your device's screen lock, and you can't set a different one. So "forgot my Locked Folder password" really means "forgot my phone's lock", and that's handled by your phone maker's screen lock recovery, not by Photos. Google also offers an optional Locked Folder backup; it is worth checking whether it was on before you try anything drastic.

Other vault and calculator apps

Most other photo vault apps on Google Play ask for a recovery email or a security question when you first open them. If you set one, the Forgot option uses it. If you skipped that screen, which is easy to do when you're in a hurry, many of these apps have nothing else to offer. Calculator-style vaults sometimes have a special code for recovery; check the app's help page or its Google Play listing for the exact steps rather than trusting a random video.

Why some vaults can reset and others can't

Every vault has to answer the same awkward question: if you forget the code, who is allowed to let you back in?

Email or account reset means the company can let you in. That's convenient, but it also means anyone who gets into your email, or anyone the company hands access to, has a path to your photos too. In many such apps the files on the phone are not strongly tied to your code, which is exactly why a reset can work.

No reset at all, as with Files by Google Safe folder, means the code is the only key. Forget it and the files are gone. Simple, but unforgiving.

A recovery key you hold is the middle way. The vault is properly encrypted, nobody else can open it, and you still have a spare key. The catch is that you have to keep that spare key safe yourself.

A vault with a reset that bypasses your code is, by definition, a vault someone other than you can open. That isn't always wrong, but it's worth knowing which kind you're trusting your photos to.

How Sealcloak handles a forgotten pattern

Sealcloak doesn't use a PIN or password for the vault. It opens with a pattern on a 5x5 grid, at least six dots, with optional fingerprint or face unlock on top. There's no account and no email, so there's no email reset either.

Instead, every vault gets its own 9-word recovery phrase when you create it. If you forget the pattern, you type the phrase on the pattern screen to get back in. Nobody else holds a copy, including the developer, because the pattern is turned into the encryption key with Argon2id and never stored. Files are encrypted on the phone with AES-256-GCM. The security page explains the details.

Wrong guesses are handled gently by default: the first four are free, then the waits grow, and changing the phone's clock doesn't skip them. If you turned on intruder photos, a photo is taken from the third wrong pattern in a row, which you'll see after unlocking. Erasing after wrong patterns is a Pro option that is off by default and needs the word PERMIT typed to turn on, so a forgetful week won't wipe your vault unless you chose that.

The honest limit: if you lose both the pattern and the recovery phrase, nobody can open that vault. That's the same property that keeps everyone else out. Your safety net is an encrypted backup, made by hand or on a weekly or monthly schedule into a folder you choose. A backup restores with the recovery phrase or the passphrase you set for it.

Make sure you never need a reset again

Whatever vault you use, a few minutes now saves a lot of panic later.

  • Set up recovery on day one. Add the recovery email, turn on Samsung's account reset, or write down the recovery phrase. Do it before you move a single photo in.
  • Write it on paper, not in the same phone. A recovery phrase saved in your notes app is lost with the phone, and readable by anyone who opens it.
  • Test it once. Lock the vault and use the recovery method while you still remember the code. You'll know it works, and you'll know where the button is.
  • Keep a backup off the phone. A copy on a computer or memory card protects against a forgotten code, a lost phone and a broken screen at the same time.
  • Use a code you'll remember, that isn't your screen lock. A vault with the same code as the phone protects nothing from someone who knows the phone's code.
  • Check what wrong attempts do. If you turn on any auto-erase option, know exactly how many tries you have.

Bottom line

A photo vault password reset works only through the recovery method the app offered and you set up: an email, a Samsung account, a phone screen lock or a recovery phrase. Try that first, slowly, and don't uninstall or clear the app while you do. If there was no recovery method, a backup is the only way back, and paid recovery tools rarely help. For the future, pick a vault whose recovery key stays with you, write it on paper, and keep an encrypted backup somewhere other than the phone.
