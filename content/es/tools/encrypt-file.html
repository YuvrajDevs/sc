Cifrar un archivo con contraseña

Bloquea cualquier archivo (un PDF, una foto, un video o un documento) con una contraseña antes de enviarlo por correo, pasarlo a una memoria USB o guardarlo en la nube. Solo alguien con la contraseña puede abrirlo.

Respuesta rápida

Para cifrar un archivo con contraseña, escribe una contraseña fuerte arriba y luego elige el archivo. Obtienes una copia .locked cifrada con AES-256-GCM. Para abrirla de nuevo, vuelve a esta página, escribe la misma contraseña y elige el archivo .locked. No se sube nada.

Cómo cifrar y descifrar un archivo

  1. Escribe una contraseña fuerte. Lo ideal es una frase de contraseña aleatoria.
  2. Elige el archivo. Obtienes una copia que termina en .locked; el original no cambia.
  3. Envía o guarda el archivo .locked. Comparte la contraseña por otro medio, por ejemplo en una llamada en vez de en el mismo correo.
  4. Para abrirlo: en esta página, escribe la misma contraseña y elige el archivo .locked. El archivo original vuelve con su nombre.

Cómo funciona el cifrado

Tu contraseña se convierte en una llave de 256 bits con PBKDF2-SHA256, con 600,000 rondas y una sal aleatoria, lo que hace lento adivinar contraseñas. Después el archivo se cifra con AES-256-GCM, que además detecta alteraciones: si cambia un solo byte del archivo .locked, se niega a descifrarlo en lugar de darte un archivo dañado. Todo pasa por el Web Crypto integrado de tu navegador, en tu dispositivo.

Privada desde el diseño

El archivo se lee, se cifra y se guarda dentro de esta pestaña del navegador. Nunca se envía a un servidor, y la contraseña nunca se guarda. Eso también significa que nadie puede recuperar una contraseña olvidada, ni siquiera nosotros, así que guárdala en un lugar seguro.

Para archivos en tu teléfono

Esta herramienta es para archivos sueltos que envías o guardas en otro lugar. Para las fotos, videos y documentos que guardas en tu teléfono Android, Sealcloak da el mismo tipo de protección automáticamente: cada archivo se cifra con AES-256-GCM al añadirlo, dentro de bóvedas que se abren con tu propio patrón, y puede crear paquetes protegidos con frase de contraseña para compartir.
