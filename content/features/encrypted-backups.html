Encrypted backups: move your vault to a new phone

An offline vault needs a plan for lost or broken phones. Sealcloak's backups are single encrypted files you keep wherever you like.

In short

Export a backup in Settings and Sealcloak writes one encrypted file to a folder you choose, then checks it can be read back. Lock it with your recovery phrase or a passphrase. To restore, install Sealcloak on the new phone, choose Restore from a backup and enter the same phrase or passphrase. Scheduled backups can run weekly or monthly on their own.

Making a backup

  1. In Settings, under Backup, tap Export backup.
  2. Choose Use my recovery phrase (recommended) or a passphrase of at least 8 characters.
  3. Pick where to save the file.
  4. Wait for Backup verified. The app reads the file back to check it.

Scheduled backups

Set up a scheduled backup to save a file by itself every week or month, to a folder you choose. If that folder is one your Drive or another sync app watches, the encrypted file goes off-phone automatically, without Sealcloak itself ever touching the internet.

Restoring on a new phone

  1. Copy the backup file to the new phone.
  2. Install Sealcloak and tap Restore from a backup.
  3. Set a pattern for the new vault and note its recovery phrase.
  4. Choose the backup file and enter its phrase or passphrase.

Importing is safe to repeat: files you already have are skipped.

Keep the file safe

The file is encrypted, but it's only as private as the place you keep it, and anyone with both the file and its key can open it. Keep the key on paper, separate from the file. The app's Security checkup reminds you if there's no recent backup. Lost the phrase too? See recovery phrase.
