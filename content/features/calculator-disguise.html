Calculator vault: hide Sealcloak as a working calculator

With calculator mode on, Sealcloak looks and works like a plain calculator. Only your secret code, then your pattern, gets anyone into the vault.

In short

Calculator mode (Pro) changes the app's icon and name to a calculator. It does real sums. To open the vault, type your 4 to 8 digit secret code and hold = for 2 seconds, then draw your pattern. A wrong code just behaves like a calculator.

Setting it up

  1. In Settings, under Disguise, tap Set up calculator mode.
  2. Choose a secret code of 4 to 8 digits and type it again.
  3. Tap Open calculator, type your code and hold = for 2 seconds.
  4. Draw your pattern. Calculator mode turns on once you've got in this way.

The icon changes when you leave the app. Some phones, such as Samsung and Xiaomi, can take a few seconds or a restart to refresh it.

Two locks, not one

The secret code only opens the calculator's door. Your pattern still protects the vault, and the files are still encrypted. Someone who stumbles on the code still needs the pattern.

Forgot the code?

Press and hold the empty calculator display, then enter your recovery phrase. You can also change the code in Settings at any time.

What it can't hide

In Android Settings → Apps, the real name Sealcloak still shows. Calculator mode is camouflage against a quick look at your home screen, not against someone checking the app list in detail. If you'd rather it look like something other than a calculator, use a custom icon instead. More on this in how to hide apps on Android.
